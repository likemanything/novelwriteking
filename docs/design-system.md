# 墨织设计体系 · 墨玉鎏金（Ink Jade & Gilt）

> 在宣纸与朱砂的东方气质上，叠加「玻璃的层次、金线的光泽、墨色的纵深」。日间像一张被灯照亮的稿纸，夜间像一方深色墨玉。

## 1. 审计结论（重构前）

| 维度 | 现状 | 问题 |
| --- | --- | --- |
| 字号 | 42 个文件里出现 **25 种** `text-[Npx]`，12 / 12.5 / 13 / 13.5 并存 | 没有字阶，层级靠感觉；大量 11–12.5px 小字 |
| 对比度 | 日间次级文字 `ink-3` 对纸色只有 **2.91:1**（夜间 3.40:1） | 不达 WCAG AA（4.5:1），而它被用在上百处 |
| 层次 | 一层纸色 + 1px 细线 + 2 档阴影 | 所有面板在同一平面，缺少纵深与焦点；「安静」但不「炫」 |
| 圆角 | `full / xl / 2xl / lg / md / 3xl` 混用，另有零散任意值 | 同类元素圆角不统一 |
| 颜色 | 31 处写死的十六进制色（封面、图表、节点状态等） | 主题切换时不跟随 |
| 响应式 | 概览页在窄屏下内容宽度 700px 撑出视口 | 手机 / 窄窗口体验破损 |
| 动效 | 仅 4 个 keyframes，无统一时长 / 缓动令牌 | 微交互风格不一致 |

保留并发扬的：线装书封面、朱砂印章、宣纸颗粒、日夜两套配色、稿纸编辑器。

## 2. 设计原则

1. **内容是主角，界面是灯光。** 稿纸、封面、画布节点是发光体；工具栏、侧栏退到玻璃层里。
2. **层次靠光，不靠线。** 用 4 级海拔（海拔越高越亮、越清晰）和渐变发丝线表达层级，减少硬边框。
3. **一处炫，处处雅。** 全局克制；只在「主行动」「焦点输入」「生成中」三个时刻给光与动效。
4. **可读性不让位。** 次级文字对比度 ≥ 4.5:1；正文最小 13px；点击目标 ≥ 32px。
5. **一套令牌，两种光线。** 所有颜色、阴影、渐变都走语义令牌，日夜自动切换。

## 3. 令牌

### 3.1 语义色（`styles.css`）
| 令牌 | 用途 | 日间 | 夜间 |
| --- | --- | --- | --- |
| `--bg` | 页面底色 | 宣纸 `#f1ecdf` | 墨玉 `#0b0d11` |
| `--surface-1` | 主内容面（卡片） | `#fbf8f1` | `#12151b` |
| `--surface-2` | 抬升面（弹层、悬停） | `#ffffff` | `#181c24` |
| `--surface-glass` | 玻璃层（顶栏、侧栏、浮层） | 纸色 72% + 模糊 | 墨玉 62% + 模糊 |
| `--text-1/2/3` | 主 / 次 / 辅助文字 | `#1f1c18 / #5b5449 / #6f6657` | `#ece5d8 / #b4ac9c / #948d81` |
| `--border-1/2` | 发丝线 / 强调线 | 棕 11% / 20% | 米 8% / 16% |
| `--seal` `--seal-2` | 朱砂主色及其深浅 | `#c23a2b / #9e2a1e` | `#e0513f / #f06a55` |
| `--gold` | 鎏金：高光、完成态、徽章 | `#b07f22` | `#d9aa4f` |
| `--jade` `--indigo` | 成功 / 信息 | 同现有 | 同现有 |

旧令牌（`--paper / --paper-2 / --ink / --ink-2 / --ink-3 / --line / --line-2`）保留为别名，现有页面不会破。

### 3.2 渐变与光
- `--grad-seal`：朱砂主按钮（上亮下深 + 顶部内高光）
- `--grad-gilt`：鎏金线（徽章、选中态描边）
- `--grad-aurora`：背景极光（朱砂 / 鎏金 / 靛青三团低饱和光晕，夜间更浓）
- `--ring-glow`：焦点光环（朱砂 18% 的 4px 外发光）
- `--spot`：卡片跟随鼠标的聚光（由 `data-spot` 元素的 `--mx/--my` 驱动）

### 3.3 字阶（Tailwind：`text-fs-*`）
| 令牌 | 尺寸 | 用途 |
| --- | --- | --- |
| `fs-2xs` | 11px | 徽章、快捷键、状态点旁的极小说明（**仅此用途**） |
| `fs-xs` | 12px | 辅助说明、表头 |
| `fs-sm` | 13px | 正文（界面）、按钮 |
| `fs-base` | 14px | 强调正文、表单 |
| `fs-md` | 15px | 小标题 |
| `fs-lg` | 17px | 区块标题 |
| `fs-xl` | 20px | 页面副标题 |
| `fs-2xl` | 26px | 页面标题（衬线） |
| `fs-display` | `clamp(38px, 6vw, 76px)` | 首页大标题（衬线） |

原先的 25 种任意值全部映射到这 9 档。

### 3.4 圆角
`--r-sm 8 / --r-md 12 / --r-lg 16 / --r-xl 22 / --r-pill 999`。控件 = md，卡片 = lg，弹层 / 大面板 = xl，标签 = pill。

### 3.5 海拔（阴影）
| 级别 | 用途 | 说明 |
| --- | --- | --- |
| `--elev-0` | 嵌入 | 无阴影，仅发丝线 |
| `--elev-1` | 卡片 | 1px 顶部高光 + 柔和下影 |
| `--elev-2` | 悬停卡片、下拉 | 抬升 2px |
| `--elev-3` | 弹层、命令面板 | 大范围柔影 + 渐变发丝线 |
| `--elev-glow` | 主行动、生成中 | 朱砂外发光 |

### 3.6 动效
| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-1 / 2 / 3` | 120 / 220 / 420 ms | 微交互 / 常规 / 入场 |
| `--ease-silk` | `cubic-bezier(.22,1,.36,1)` | 默认（已有） |
| `--ease-snap` | `cubic-bezier(.3,1.4,.5,1)` | 按压回弹 |

全部尊重 `prefers-reduced-motion` 与设置里的「减少动态效果」。

## 5. 无障碍基线
- 文字对比度 ≥ 4.5:1（大字 ≥ 3:1）；已验证 `text-3`：日间 `#6f6657` 对纸色 4.89:1、对卡片 5.33:1；夜间 `#948d81` 对墨玉 5.87:1。
- 所有交互元素有可见焦点（朱砂光环）；图标按钮都有 `aria-label`。
- 动效可关闭；颜色不作为唯一信息载体（状态同时有图标 / 文字）。
- 窄屏（≥ 360px）无横向滚动；点击目标 ≥ 32px。

## 6. 已落地（第二轮）
- 概览页窄屏溢出已修（网格显式 `grid-cols-1` + `min-w-0`）。
- 全局焦点环移入 `@layer base`：组件与工具类可覆盖，修复搜索框出现多余红框。
- 命令面板、通知、弹层统一为玻璃层 + 渐变发丝线 + 模糊背景；选中项带朱砂光条。
- 写作台稿纸：正文落在一张带圆角与海拔的「纸」上，写得越多纸越长；状态栏改为容器查询，不再换行。
- 首页底部横带由遮罩渐变改为线条自身淡出，与极光背景无缝衔接。

## 7. 落地顺序（路线图）
1. 令牌与全局：语义色、字阶、海拔、渐变、背景极光、聚光、对比度修正。
2. 基础组件：Button / Input / Surface / Badge / Tabs / Modal / Toast。
3. 外壳：项目侧栏与顶栏改玻璃层，文字标签与提示。
4. 页面：首页、书架、概览（修复窄屏）、写作台、短剧画布、设置。
5. 字号一次性迁移到字阶，并加一条检查脚本防止回退。
